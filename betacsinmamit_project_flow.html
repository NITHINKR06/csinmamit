Guard logic
UserGuard
  • Checks user !== null
  • Redirects to / if not signed in
  • Wraps /profile route
CoreMemberGuard
  • Checks user.role === "coreMember"
  • Shows "Access Restricted" page
  • Optional permission check
AdminGuard
  • Reads adminUser from AdminAuthContext
  • Redirects to /admin/login
  • Separate from regular auth

External service flows
Cloudinary (image upload)
  • Used by admin EventForm
  • Unsigned upload via preset
  • VITE_CLOUDINARY_CLOUD_NAME
  • VITE_CLOUDINARY_UPLOAD_PRESET
  • Returns hosted image URL → stored in event.imageUrl
Razorpay (payments)
  • Client-side only (no backend order API)
  • VITE_RAZORPAY_KEY_ID used in checkout
  • Payment verified only by presence of payment_id
  • No server-side signature check
Web3Forms (email)
  • Used only for admin login token email
  • VITE_WEB3FORMS_ACCESS_KEY required
  • POST to api.web3forms.com/submit
  • Sends static ADMIN_LOGIN_TOKEN in body
